# A separate 8 GB Contabo VPS instead of the shared 4 GB server

The plan was to run k3s on Jennifer's existing 4 GB VPS, but our estimate of 2.5–3 GB for phases 1–2, before Prometheus, Grafana, Loki and several backend replicas, would leave 4 GB at its limit during the load tests we demo, which is when Kubernetes starts evicting pods. We rented a dedicated Contabo Cloud VPS 4 for the project instead (4 vCPU, 8 GB RAM, 100 GB SATA SSD, 200 Mbit/s, EU region, Ubuntu 24.04, KVM), on a monthly term at about €7 a month that can be cancelled after the defence. It was the cheapest 8 GB KVM plan we could order without a contract in October 2026: OVHcloud's VPS-2 was out of stock in every EU location, Hetzner's equivalent cost about €36 a month after its June price rise, and netcup needs a 12–24 month term. The cost is a SATA disk and vCPUs shared with other customers; the 5,000-row ticket table fits in RAM, so the disk should not bind, but load test results can vary between runs, so we repeat each run and report a typical result.
